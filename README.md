🔥 Calories Burnt Prediction
A Machine Learning project that predicts the number of calories burned during exercise based on user characteristics such as age, gender, height, weight, exercise duration, heart rate, and body temperature.

🚀 Features
Data preprocessing and cleaning
Exploratory Data Analysis (EDA)
Feature correlation analysis
Machine Learning model training
Model evaluation and prediction
